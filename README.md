# Northstar Studio

A responsive, single-page website for a small creative studio. It includes a welcoming homepage, an about section, a contact form with client-side validation, and a compact mobile navigation menu.

## Run locally

No build step is required. Open `index.html` directly, or start a local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
